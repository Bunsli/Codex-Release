# Codex

Download `MMOCompanion-<version>-win-x64.zip` from the latest release (Releases, on the right).

1. Unzip it into a folder you own, e.g. `Documents\Codex` — not `Program Files`.
2. Run `MMOCompanion.exe`. The first time, Windows may warn about an unknown publisher: **More info → Run anyway**.

The app updates itself: it checks for a new version shortly after it starts, downloads it in the background, and installs it the next time you close the app.
